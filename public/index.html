🔥 LoreForge

Turn your internal wiki into a JSON API.

Point LoreForge at a MediaWiki, a Fandom wiki, a Confluence space, or any site. It ingests the pages, an LLM structures them into clean entities, and you query everything over a simple REST API. Self-hosted, open source (MIT).

👋 You're browsing the public demo.
This demo is rate-limited, read-only, and capped — it can't stand in for your own install, and you can't add new sources here. Run LoreForge on your own hardware for the full thing:
github.com/mortis2600/LoreForge
What it's for:
  • Company wikis nobody can query — expose Confluence/MediaWiki pages as JSON for bots, dashboards, and RAG pipelines
  • Fan wikis and lore sites — structured characters, items, and trivia over REST
  • Documentation sites — turn sprawling docs into an API your tools can actually use
Try it:
  • /api/v1/meta/sources — what's in the database
  • Search explorer — query the lore
  • Admin — manage LLM providers, sources, and ingest jobs
  • GET /api/v1/:source/:entityType/:name — look up one entity
Ingest a new source:
node src/factory.js my_source
Sources live in config/sources.json. See the README for the adapter docs.
